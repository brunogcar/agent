# 📈 B3 (Brasil, Bolsa, Balcão)

Brazilian stock exchange data via the CSV bulk download API.

## Sub-domains

| Sub-domain | What | Storage | Source |
|---|---|---|---|
| [API](API.md) | Market data: instruments (52 cols), trades (15 cols), derivatives (17 cols) | `memory_db/b3/{table}.db` | `arquivos.b3.com.br/api/download/` |
| [DIVIDENDS](DIVIDENDS.md) | Corporate actions: cash dividends, stock dividends, subscription rights (per-ticker) | `memory_db/b3/dividends.db` | `sistemaswebb3-listados.b3.com.br` |
| [BRAPI](BRAPI.md) | Current quotes (15-min delay), historical OHLCV, ticker list — brapi.dev free API | `memory_db/b3/brapi.db` | `brapi.dev/api` |
| [COTAHIST](COTAHIST.md) | B3 official historical trade data (annual ZIP, OHLCV for all securities since 2010) | `memory_db/b3/cotahist.db` | `bvmf.bmfbovespa.com.br/InstDados/SerHist/` |
| [INDEX](INDEX.md) | B3 indices: IBOV, SMLL, BDRX, IFIX, IDIV (5 active + 26 catalogued). Composition (constituents + weights) + historical values. | `memory_db/b3/index.db` | `sistemaswebb3-listados.b3.com.br` |

## API Migration (2026)

### v2.0 (2026-08-24): CSV Bulk Download

B3's paginated JSON API (`/tabelas/table/{tableName}/{date}/{page}`) was
fundamentally limited: 4 columns only, 22-minute sync time for derivatives
(2,283 pages × 20 rows), server-side throttling, and 504 timeouts on ~40%
of pages.

Replaced with the 2-step CSV bulk download API:

```
Step 1: GET /api/download/requestname?fileName={tableName}&date={date}
  → {"token": "...", "file": {"name": "...", "extension": ".csv"}}

Step 2: GET /api/download/?token={token}
  → Full CSV file (semicolon-separated, ALL columns, ALL rows)
```

**CRITICAL:** The download URL requires a trailing slash (`/api/download/`).
Without it, B3 returns an HTML consent page instead of the CSV.

### Performance (derivatives, 2026-08-21)

| | Old (JSON pagination) | New (CSV bulk) |
|---|---|---|
| HTTP requests | 2,283 | 1 |
| Sync time | 1,331s (22 min) | ~1.3s |
| Columns | 4 | 17 |
| Rows | 13,980 (many 504 timeouts) | 45,653 (all rows) |

### Column counts per table

| Table | Old (JSON) | New (CSV) | New columns include |
|---|---|---|---|
| instruments | 4 | 52 | ISIN, AsstDesc, SctyCtgyNm, XprtnDt, BaseCd, CrpnNm, ... |
| trades | 4 | 15 | ISIN, MinPric, MaxPric, TradAvrgPric, OscnPctg, AdjstdQt, ... |
| after_hours | 4 | 15 | Same as trades |
| derivatives | 4 | 17 | ISIN, Asst, XprtnCd, VartnOpnIntrst, DstrbtnId, CvrdQty, TtlPos, ... |

### v1.0 (2026): Paginated JSON API (DEPRECATED)

B3 migrated from the old 3-step CSV download flow to a React SPA with a
paginated JSON API. This was the original implementation:

```
GET /tabelas/table/{tableName}/{date}/{page}
 → {"name", "columns": [...], "values": [[...], ...], "pageCount": N}
```

20 rows per page, JSON format, no token needed. **Deprecated in v2.0**
due to the performance + column limitations above.

## Tables

| Table | API Name | Key | What |
|---|---|---|---|
| instruments | InstrumentsConsolidated | TckrSymb | All listed securities (52 cols): ticker, ISIN, company name, segment, governance, maturity, strike |
| trades | TradeInformationConsolidated | TckrSymb+RptDt | Daily regular session (15 cols): prices, volume, VWAP, oscillation |
| after_hours | TradeInformationConsolidatedAfterHours | TckrSymb+RptDt | After-hours session trades (same 15 cols as trades) |
| derivatives | DerivativesOpenPosition | TckrSymb | Open interest (17 cols): futures, options, covered/uncovered qty, forward price |

## CSV Format

- Semicolon-separated (`;`)
- ISO-8859-1 encoding (Portuguese accents)
- 3 of 4 tables have a `Status do Arquivo: Final` line before the header
  (derivatives does NOT — its first line IS the header)
- No quoting/escaping needed (B3 doesn't embed semicolons in values)

## Data Availability

B3 publishes trade data with a delay. Today's data is usually partial during
market hours (9:00-18:00 BRT) and complete after market close (~19:00 BRT).

**[v2.1] Partial data skip:** The sync engine detects B3's "Status do Arquivo"
line (`Final` vs `Parcial`). If the data is `Parcial` (intraday snapshot),
the sync skips and keeps the previous `Final` data — partial data never
overwrites complete data. The sync returns `{status: "skipped_partial"}`.

For the full daily dataset, sync after 19:00 BRT or the next morning.

## Bridge Integration

The `instruments` table has `TckrSymb` (ticker) + `CrpnNm` (company name). The CVM `cad` data source has `CNPJ` + `CD_CVM` + `DENOM_SOCIAL`. The bridge joins them: ticker → CrpnNm → DENOM_SOCIAL → CNPJ → CD_CVM → financial statements.

## Future: BDI Portal

B3 announced that the public data pages were decommissioned on 2026-03-31
and migrated to the BDI portal (`https://arquivos.b3.com.br/bdi/tabelas`).
The "Quadro Analítico das Posições em Aberto" (analytical open positions
table) is expected on BDI from 2026-06-30.

If the `/api/download` endpoint is decommissioned, investigate the BDI
portal as the replacement. (Discovered by ChatGPT during the 2026-08-24
multi-LLM code review.)
